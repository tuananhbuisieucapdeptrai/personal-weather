## Findings

- **No installs needed for Tuan Anh's code.** It is stdlib only. PMV is hand-written: pythermalcomfort would add ~300 MB (numba/scipy/numpy). Agreement with pythermalcomfort is checked in `tools/eval/check_pmv.py`: max |ΔPMV| 0.0009 over 522 conditions.
- **App Lab already ships numpy 2.5.4, OpenCV 4.13.0 and `arduino.app_utils`.** This is relevant for Minh's vision work; nothing to pip-install.
- **Speed on the board (container):** `comfort.estimate()` including the band takes 3.1 ms; PMV alone takes 0.03 ms. The budget is 50 ms.
- **Device API** (`api.py`) works in the container: GET /state 200, POST /control 200, invalid body 400.
- **Hub reachable from inside the container** at `http://192.168.0.7:8080/ping` (outbound through the App Lab Docker network).
- **`state/` lives in the mounted app folder** (`~/ArduinoApps/<app>/python/state` on the host), so pseudonyms and the hub URL survive container restarts.
- **Port 8000:**
  - App Lab apps run on their own Docker network. A port is reachable from the laptop only if `app.yaml` declares it.
  - `device/app.yaml` now has `ports: [8000]`; it was `[]`.
  - Minh's `vision-check` app currently publishes 8000. Only one of the two apps can run at a time.
